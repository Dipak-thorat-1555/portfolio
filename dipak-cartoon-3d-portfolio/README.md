# Dipak Thorat — Cartoon 3D Portfolio

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` using Live Server or your browser.

## Cartoon movement
- The hero cartoon gently bobs up and down.
- Eyes blink.
- Arms animate as if typing.
- The contact cartoon waves.
- On desktop, the hero character tilts slightly toward the pointer.
- Section content reveals while scrolling.

The cartoon is built from CSS shapes, so it works without an external 3D library or downloaded character assets. It is a stylized CSS cartoon rather than a photorealistic 3D model.
